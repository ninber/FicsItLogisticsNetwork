How to read this monitor
Requests activate only when the requester station inventory is empty. Fresh pickups need one full vehicle load at one provider; matching retained cargo takes priority and can be a partial load; stock at different providers cannot be combined. Truckload ranges use sampled vehicle classes and slot counts; customized per-slot filters can differ.
Rates are observed net station inventory changes, not factory production rates. Batch-fill estimates predict when a provider may have a truckload, not when a delivery will arrive. Occupied or reserved inventories do not get rate estimates. External storage buffers are not observed. “Observed empty” starts when this dashboard first sees an empty station.
Snapshots are collected over several seconds with one object per pass, then refreshed while this page is open. Check timestamps before interpreting rapidly changing stock. Route availability is not inferred from physical proximity.
